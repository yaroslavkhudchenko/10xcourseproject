## Stack

- TypeScript (strict), on Node 24 for tooling.
- Astro 7, server-rendered on every request (`output: "server"`), with React 19 components hydrated in the browser where interaction is needed ("islands").
- Tailwind CSS 4 for styling; UI texts are written in Polish inside the code (no translation catalog).
- Supabase: Postgres with row-level security, accessed with `@supabase/supabase-js` from server code (no ORM; queries are written in the service files).
- Cloudflare Workers runtime for deployment.
- Validation with zod (imported as `astro/zod`).
- Tests: Vitest (Node) for unit and integration tests; Playwright for browser tests; Node scripts that check database rules against a local Postgres.
