# Glossary: Drogeria Radar

Use these words in code, tests, commits and conversations. When a name in the code differs from the term, the term wins in new code; renaming old code is a separate decision.

## Watchlist and search

| term            | means                                                                                                                                                                                               | name in code                                        | don't call it                                                                           |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- | --------------------------------------------------------------------------------------- |
| watched product | A product on one user's list: their own copy of the item they picked, with its own shop.                                                                                                            | `watchlist_items`, `WatchlistItem`; its id `itemId` | "item" (that's a shop's item), "entry" (that's a search result), `productId` for its id |
| watchlist       | One user's private list of watched products, which no other user can see or infer.                                                                                                                  | `/watchlist`, `listWatchlist`                       | "household list"                                                                        |
| own shop        | The shop a product was picked in. Its item there prices the product and is never matched or re-pinned.                                                                                              | `source` on `watchlist_items`                       | "source" alone (it also means a price's provenance)                                     |
| matched shops   | Every priced shop except the product's own. Each holds one decision for the product.                                                                                                                | `matchedShopsOf(source)`                            | `MATCHED_SHOPS` (gone), "other shops"                                                   |
| product search  | One search of all four priced shops at once, run only when the user searches. Its shop line says each shop's result count, „brak wyników” or „nie odpowiada”, and Rossmann may add a spelling hint. | `searchShops`, `shopLinesOf`, `spellingHint`        | "lookup" (that's matching in one shop)                                                  |
| search entry    | One product in the search results. It joins items of different shops that the matching rule accepts as one.                                                                                         | `SearchEntry`, `ResultEntry`                        | "entry" alone, "row"                                                                    |
| „Dodaj”         | Adds a search entry's item from the first shop in shop order, and stores nothing else.                                                                                                              | `addToWatchlist`, `POST /api/watchlist`             | "import", "subscribe"                                                                   |
| „Na liście”     | A search entry whose item the list already holds, as a product or as a match.                                                                                                                       | `onListOf`                                          | —                                                                                       |
| removal         | Deletes a watched product with its decisions. No price is ever deleted.                                                                                                                             | `removeFromWatchlist`                               | "hide", "archive"                                                                       |

## Matching

| term             | means                                                                                                                                                                       | name in code                                                      | don't call it                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| shop item        | One shop's own item, known by the shop and that shop's id. It is the product's anchor in that shop, and everyone who watches it shares its prices.                          | `PriceKey`; `shopItemId` (`sourceItemId` for the own shop's item) | "item" alone, "pinned item", the shops' `sku`, `ID` or `objectID` outside the adapters |
| candidate        | A shop's item offered as a possible match, with its name, size and price.                                                                                                   | `ShopCandidate`, `CandidateOption`                                | `ProductCandidate` (that's an item offered for „Dodaj”)                                |
| lookup           | Searches one matched shop for candidates, by EAN first and then by name.                                                                                                    | `lookupInShop`, `lookupChoicesInShop`                             | "search" (that's the user's product search)                                            |
| matching rule    | Accepts on its own only the single candidate that shares an EAN and the size and whose brand doesn't differ, or else one the name check passes. Otherwise the user chooses. | `pickMatch`; `decided_by = 'auto'`                                | "auto-match" for anything the rule didn't accept                                       |
| name check       | Accepts a candidate by its name where EANs can't decide, under strict word rules.                                                                                           | `acceptedByName`, `passes`                                        | "fuzzy match", "similarity"                                                            |
| choice           | The candidates shown for the user to pick from: at most 3 after a lookup, 6 in a re-pin.                                                                                    | `orderChoice`; view `choose`                                      | "results"                                                                              |
| decision         | The stored outcome for one product in one matched shop: a match, a decline or not found.                                                                                    | `watchlist_matches`, `ShopMatch`; guarded by `admitDecision`      | "match" for all three states                                                           |
| match            | A decision that pairs the product with one shop item, accepted by the rule or picked by the user.                                                                           | state `matched`; `MatchedItem`                                    | "pin"                                                                                  |
| confirm          | The user picks a candidate („To ten produkt”).                                                                                                                              | action `confirm`; `decided_by = 'user'`                           | "approve"                                                                              |
| decline          | The user turns down every candidate of one shop („Żaden z nich”).                                                                                                           | action `decline`; state `unmatched`                               | "unmatched" for a lookup that found nothing                                            |
| not found        | The lookup found nothing; the user can look again („Szukaj ponownie”).                                                                                                      | `not_found`; `retry`                                              | "unmatched", "declined"                                                                |
| undecided        | No decision is stored yet for a matched shop.                                                                                                                               | no row; `ListMatchState` `none`                                   | "not found", "pending"                                                                 |
| re-pin           | Opens a new choice to change a match or a decline („Zmień”, „Dopasuj ponownie”). It never accepts on its own and changes only the decision its form showed.                 | `repin`; `replaces`                                               | "re-match", "edit"                                                                     |
| guardian         | The one place that admits or refuses a change to a watched product's decisions, before anything is stored.                                                                  | `admitDecision`, `watchedProductOf` (`watched-product.ts`)        | "validator"                                                                            |
| outdated form    | A decision form shown before the stored decision changed; the guardian refuses it, and the page says the decision was already stored.                                       | refusal `outdated-form`                                           | "stale" (that's a price)                                                               |
| suspicious match | A match whose size or brand definitely differs, known on both sides.                                                                                                        | `matchDifferences`, `ListMismatch`                                | "wrong match"; "mismatch" for a size or brand that's unknown                           |
| „Do sprawdzenia” | The list's to-do filter: products with a matching problem or a price that isn't fresh.                                                                                      | `?f=check`, `needsCheck`, `ListRow.check`                         | "check" alone (that's a price check)                                                   |
| EAN              | A barcode number that helps a lookup and never decides identity.                                                                                                            | `eans`                                                            | "GTIN" outside the adapters                                                            |
| size             | An amount with its unit (ml, g or pcs); two sizes are equal within 0.1 %.                                                                                                   | `Size`, `sizesEqual`                                              | Hebe's `Pojemność`                                                                     |
| brand            | The maker's name. Two brands agree when one starts with the other, once both are normalised.                                                                                | `brandsAgree`                                                     | —                                                                                      |
| caption          | Rossmann's line beside the name, which holds the shade, the scent or the strength.                                                                                          | `caption`                                                         | "description"                                                                          |
| set              | A product whose name says „zestaw” or joins items with „ + ”.                                                                                                               | `isSetName`                                                       | "bundle"                                                                               |

## Prices and the judgement

| term                 | means                                                                                                                                                                         | name in code                                       | don't call it                                                                                        |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| price observation    | One stored fetch of a shop item's price, or of its absence. It is append-only and shared by the item's watchers. Its source is always a shop fetch until manual entry exists. | `price_observations`, `PriceCheck`                 | "price cache", "snapshot"; "source" alone for its provenance                                         |
| watcher              | A user who has the shop item on their list or matched. Only watchers read or add its prices.                                                                                  | the observations' RLS policies; `productPriceKeys` | "subscriber", "follower"                                                                             |
| current price        | What the shop sells at online now, a promotion's price included. It is never a shelf price.                                                                                   | `ShopOffer.price`                                  | "shelf price", "store price"                                                                         |
| regular price        | The price before a reduction.                                                                                                                                                 | `regularPrice`                                     | "old price" (Rossmann's `oldPrice` stays in its adapter)                                             |
| promotion            | A fresh offer that carries a regular price or an end date.                                                                                                                    | `onPromotion`; `promoEndsOn`                       | Rossmann's `promotion` tag, which is a campaign                                                      |
| declared 30-day low  | The 30-day low a shop shows beside a price, as the shop declares it.                                                                                                          | `lowestPrice30d`                                   | "Omnibus price" outside Hebe's adapter, "history low"                                                |
| history low          | The lowest orderable price the app recorded for the product's shop items in the 30 days before today.                                                                         | `history_low`                                      | "30-day low"                                                                                         |
| age                  | How long ago a price was fetched; every shown price carries it.                                                                                                               | `ageText`, `pricedAt`, `lastCheckedAt`             | —                                                                                                    |
| fresh / stale        | Fresh: fetched within 24 hours, with its promotion not over. Stale: anything older, shown with its age and never cheapest.                                                    | `PriceState`, `STALE_AFTER_MS`                     | "stale" for a check due for refetch (`needsRefetch`, after 15 minutes) or for a form from an old tab |
| missing              | The shop no longer returns the item; its last price stays, out of date.                                                                                                       | status `missing`                                   | "not found" (that's a matching state), "unavailable"                                                 |
| unread               | No readable answer or stored row. It is never read as missing or not found.                                                                                                   | `unread`, `ShopUnavailable`                        | "unavailable" (that's not orderable), "missing", "empty"                                             |
| orderable online     | The shop sells the item online now.                                                                                                                                           | `available`                                        | "in stock", "available" without "online"                                                             |
| cheapest             | The lowest fresh, orderable price among two or more shops; tied shops are all marked.                                                                                         | `compareShops`; verdict `cheapest`                 | "best price"                                                                                         |
| verdict              | What a product's prices come to: unread; cheapest; only, priced in one shop; unavailable, fresh but not orderable online; stale, a missing item included; or none.            | `PriceVerdict`, `verdictOf`                        | "judgement"                                                                                          |
| last known price     | The latest stored price, shown with its age when no current one is.                                                                                                           | the view's `priced_at`                             | "current price"                                                                                      |
| gap                  | A shop shown without a price, never as a blank or a zero.                                                                                                                     | rendered, not named                                | "0 zł"                                                                                               |
| good-price judgement | Today's cheapest or only price is „Dobra cena!” below the comparison and „Zwykła cena” at it or above.                                                                        | `judgementOf`, `PriceJudgement`                    | "verdict", "deal"                                                                                    |
| comparison           | What the judgement compares with: the declared 30-day low until history is enough, then the lower of the history low and the declared low.                                    | judgement basis `shop`, `history`                  | —                                                                                                    |
| enough history       | 30 days on the list, and orderable prices on 5 Warsaw days in the 30 days before today.                                                                                       | `HistoryState` `enough`                            | —                                                                                                    |
| refresh              | Fetches prices on the user's action („Odśwież ceny”), or when a product page finds them 15 minutes old.                                                                       | `refreshPrices`, `autoRefreshOf`                   | "sync"                                                                                               |

## Shop access

| term           | means                                                                                             | name in code                                        | don't call it                                                       |
| -------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------- | ------------------------------------------------------------------- |
| shop           | One of the four drugstore chains compared, as an online shop.                                     | `ShopId`                                            | "store" (a physical shop)                                           |
| priced shop    | A shop the code compares; taking one out of the list needs a deploy.                              | `PRICED_SHOPS`                                      | "supported shop", "matched shop", "switched off" for a stopped shop |
| shop gate      | The one way to a shop. It enforces the cap, the pause and the stop.                               | `gate.fetch`, `createShopGate`                      | a direct `fetch`                                                    |
| request cap    | At most this many requests a minute to one shop from the whole deployment, 30 by default.         | `cap_per_minute`; outcome `capped`, shown as `busy` | "rate limit" (that's the shop's own 429)                            |
| paused         | A shop that asked to slow down, with a 429 or a 503 and a Retry-After, until a set time.          | `paused_until`; `rate-limited`                      | "stopped"                                                           |
| stopped        | A shop the gate switched off after a 403 or a bot challenge, until the owner switches it back on. | `enabled = false`; `blocked`, `stopped`             | "switched off" (that's leaving `PRICED_SHOPS`), "disabled"          |
| own navigation | A request the user started on this site. Only those, or an explicit action, may reach a shop.     | `isOwnNavigation`                                   | —                                                                   |
| shop adapter   | The translation of one shop's API into the app's terms.                                           | `ShopAdapter`, `SHOP_ADAPTERS`                      | —                                                                   |

## People

| term  | means                                                                                                                   | name in code      | don't call it                                  |
| ----- | ----------------------------------------------------------------------------------------------------------------------- | ----------------- | ---------------------------------------------- |
| owner | The person who runs the deployment: they make accounts and links and switch stopped shops back on, all outside the app. | no role in code   | "owner" for a row's user (say "user"), "admin" |
| user  | A signed-in person with their own private list.                                                                         | `user`, `user_id` | "shopper" in code                              |
